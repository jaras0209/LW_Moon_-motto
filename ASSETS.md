# Artwork

The local artwork is derived from the Mid-Autumn card illustration approved in this conversation.
card-background.webp has no fixed quote, heading, footer sentence, reference, or rabbit text baked into it.
All message text and the single-color rabbit are painted at runtime by card-renderer.js.
moon.png is a text-free, transparent moon crop; rabbit.svg contains the shared leaping silhouette.
No font files are included. No external image server or generation API is used by the website.
